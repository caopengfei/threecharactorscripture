# 应用图标重设计——「暖阳积木」设计文档

- 日期：2026-10-04
- 状态：已经视觉伴侣两轮比选定稿（第一轮 4 方向 + 基线，用户选 B「暖阳积木」；第二轮 4 变体，用户选 B1「三色积木 + 射线太阳」）
- 范围：启动图标（mipmap 全密度）+ TV banner；不动 manifest、不改任何代码逻辑

## 背景与问题诊断

用户反馈「apk 的图标不够美观」。现状（`tools/gen_icons.py` 生成）：

- 启动图标：珊瑚圆角方块外还包一圈奶油底——两层边框像"贴片"，且"三"字只占画面一半，单薄；
- banner：构图尚可，但与新图标方向不同源，且珊瑚印章"学"与整体童趣风格关联弱。

关键修正：真图标应满版出血（圆角一次成型、透明角），不再"方块里画方块"。

## 启动图标规格

满版正方形，圆角半径 22%（PNG 自带透明圆角），4x 超采样渲染后 LANCZOS 降采样。以下坐标以边长 S 归一化。

- 背景：奶油渐变 `#FFF8EC → #FFE6C7`（纵向，与 app 首页底色同源）
- 主体「三」：三条胶囊积木（圆角 = 半高），抽象自"三"字三横（**中横短**）：
  - 宽 0.56S / 0.44S / 0.56S，高 0.105S，垂直中心 y = 0.365S / 0.515S / 0.665S
  - 旋转 -2.5° / +2° / -1.5°（微倾，玩具感）
  - 配色：蜜橙 `#D4954A`（上）/ 珊瑚 `#FF8A65`（中）/ 叶绿 `#80B26E`（下）
  - 立体感：每块底部叠 14% 高的同形状深一号色（RGB 各 -30）底唇
- 太阳：圆心 (0.78S, 0.21S)，半径 0.075S，`#F7B26E`，8 根射线（半径 1.45r→1.85r，线宽 0.016S）
- 图标内**不出现文字**（纯图形，48px 下仍可辨）
- 密度产物：mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192 → `mipmap-*/ic_launcher.png`

## Banner 规格（640×360）

按 2x（1280×720）渲染后缩至 640×360，坐标均 @2x。背景奶油渐变同上、直角满幅。

- 左侧文字（字体 `tools/LXGWWenKai-Medium.ttf`，文楷 Medium）：
  - 「三字经」260px，墨棕 `#5A4634`，锚点 lm (90, 300)
  - 「亲子共读 · 逐句跟学」58px，浅棕 `#8A6D4E`，锚点 lm (95, 545)
- 右侧图形（与图标同构）：
  - 积木三：宽 300 / 230 / 300，高 58，中心 (1065, 310 / 450 / 585)，旋转与配色同图标
  - 太阳：圆心 (1140, 140)，半径 52，`#F7B26E`，8 射线（1.45r→1.85r，线宽 22）
- 产物：`drawable-nodpi/banner.png`

## 工具与产物变更

- 重写 `tools/gen_icons.py`：按上述规格程序化生成（超采样管线），保留"源字体存在才可运行"的检查（banner 依赖文楷 Medium）；产物覆盖 mipmap 与 banner PNG
- **不引入自适应图标**（non-goal）：本 app 的真实展示面只有 TV 桌面 banner 与设置页图标；小米盒子 4 是 API 23（自适应图标 API 26+ 不生效），TV 桌面只认 banner——legacy 密度 PNG 即所见
- README 若有图标截图/描述，落地后同步

## 验收标准

1. `python tools/gen_icons.py` 全量重新生成；192 与 48 两档抽查观感
2. `assembleDebug` 打包，安装到模拟器（emulator-5554 / szj_tv）与小米盒子（192.168.31.149:5555）
3. adb 截屏验收：TV 桌面 banner 行（两台）、设置→应用里的图标
4. 无代码改动，既有测试不受影响
